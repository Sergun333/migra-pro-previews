# migra-pro-previews

Публичные демо-макеты посадочных страниц Migra-Pro для согласования с командой и подрядчиками.

- Это **черновые макеты**, не продакшен-вёрстка.
- Данные-плейсхолдеры («уточняется») заменяются на финальном этапе.
- Внутренние материалы и рабочие документы проекта здесь **не публикуются** — они в приватном репозитории.

## Доступные превью

Полный список — на главной странице витрины: **https://sergun333.github.io/migra-pro-previews/**

Список ведётся не руками: `index.html` пересобирается по фактическому составу репозитория скриптом `служебное/пересборка-индекса-витрины-превью.ps1` основного проекта, поэтому опубликованная страница из навигации не выпадает. Перечислять страницы здесь не нужно — второй список неизбежно отстанет от первого.
